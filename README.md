## 机房和线路：访客在哪，机器就放哪

线路选择其实是地理问题，不是技术问题。

**国内访客为主。** 三条路可选。9929 走联通精品网，国内三网延迟普遍在 170ms 上下，晚高峰的稳定性比普通国际线路好，缺点是带宽只有 50Mbps。4837 的优势是带宽给到 300Mbps、流量 3000GB，代价是延迟看省份和运营商，公开测试里从 170ms 到 380ms 都有。香港三网直连和日本原生 IP 三网优化，是给华南和华东用户的短路径方案，延迟比美国低，但流量额度小、单价高。

**东南亚访客。** 新加坡原生 IP，但官网明确写了非大陆直连优化，部分地区联通和移动直连尚可。做东南亚市场没问题，接国内流量不合适。

**北美、欧洲访客。** 纽约、芝加哥、英国、德国四个点。这类站本来就不该指望国内访问快，本地访客的体验才是重点。

有一条判断标准可以直接用：官网标注“非大陆优化网络”的产品组，包括新加坡 BGP、纽约、芝加哥、台湾、英国、越南，别拿来接国内流量，SSH 都可能卡。

## 从下单到 WordPress 上线

流程本身不复杂，第一次走大概一两个小时，熟了半小时内能搞定。

1. **下单选线路。** 付款走支付宝，机器自动开通、即时交付，不用等人工审核。
2. **收开通邮件。** 里面有 IP、root 密码，Debian、Ubuntu、CentOS 都能装，需要 Windows 的也可以选。
3. **SSH 登录。** 第一件事改密码、上 SSH 密钥，比裸密码安全得多。
4. **装面板。** 新手走宝塔，一行命令装完 LNMP，剩下的在浏览器里点。愿意花一两个小时看文档的，可以试 WordOps 或 CyberPanel 这类为 WordPress 优化的轻量面板，Nginx、FastCGI 缓存、Redis 一次配好，性能比手动搭要好。

## 常见问题

**完全不懂 Linux，能用吗？**
能。装个宝塔面板，日常操作都在浏览器里。SSH 只在第一次装面板时用一次，命令复制粘贴就行。但服务器出问题时还是得看日志、查进程，纯小白要有心理准备。

**1 核 1G 真的能跑 WordPress？**
能跑，但插件别超过十个，别上 WooCommerce。想后台不卡、多开几个 PHP 进程，直接上 2G。

**开通后发现 IP 连不上怎么办？**
先 ping，连不上就开工单。48 小时窗口内也可以直接申请退款重开。

**年付会不会续费涨价？**
官网的循环优惠码是续费同价，但标价本身会不会调整，官方没有公开承诺。年付省的是当下的钱，不是终身锁价。

**支持装 Windows 吗？**
支持，下单时选系统即可。

**能换机房吗？**
不同机房是不同产品组，本质上是两台不同的机器，没有“换”这个操作，只能退掉重开。
